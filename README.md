# 📊 Vrinda Store Data Analysis

Vrinda Store wants to analyze its **2022 sales performance** to understand customer behavior and identify growth opportunities for 2023.  
This project focuses on **data cleaning, analysis, and dashboard creation using Excel** to derive actionable business insights.

---

## 🔍 Project Overview

The objective of this project is to create an **annual sales report** for Vrinda Store by analyzing historical sales data.  
The analysis helps stakeholders answer key business questions such as:
- Who are the top customers?
- Which states generate the highest sales?
- Which sales channels perform best?
- What trends can be leveraged to improve sales in 2023?
